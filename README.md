# diffusion-models-project
This is a project on Generating Images with Diffusion models for the course Machine Learning in Physics in Astronomy

The ddpm package contains the basic architecture, the example_usage_ddpm notebook shows how to use it. The notebooks folders contain individual notebooks, if one wants to edit them, copy them and rewrite your initials in the front, it is not really possible to merge two different versions of the same notebook.

The experiment workflow notebook contains some functions which I found useful on a notebook level workflow
